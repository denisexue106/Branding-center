# Branding Center

An interactive HTML prototype of Branding Center, a brand asset manager for
landing pages and emails. Built at Keap, acquired by Thryv.

Open `index.html` in a browser. No build step, no dependencies.

## What it covers

**Branding.** Upload and manage logos, set a primary, build a brand colour
palette, choose a brand font.

**Style guide.** A form that drives a live Style Preview: surface and text
colours, link colours and underline behaviour, per level font, weight and
alignment for H1 to H4 and body, and button fill and corner radius. Each
heading level keeps its own settings.

**Synced block.** Reusable content blocks that update across every landing
page and email at once. Search, hover actions, per card menus, pagination.

## Notes

The brand face used in the product is not web hosted, so the interface falls
back to a system grotesk. Synced block thumbnails are CSS stand ins rather
than the real imagery.
